# 퀵 정렬 피벗 선택 방법에 따른 비교 횟수 분석

## 1. 개요
- 무작위 정수(중복 허용)를 오름차순으로 정렬하고, 피벗 선택 방법 세 가지(First, Random, Median-of-Three)의 **숫자 비교 횟수**를 측정했다.
- 데이터 크기: n = 1,000 / 2,000 / 4,000 / 8,000 / 16,000 / 20,000
- 같은 크기에서는 세 방법이 동일한 원본의 복사본을 사용했다.
- 피벗 선택 함수만 다르고, 분할 알고리즘과 재귀 구조는 모두 같다.
- 비교 횟수에는 분할 중 `데이터 값 vs 피벗` 비교와 Median-of-Three의 중앙값 결정 비교를 포함했다. 인덱스·종료 조건 검사, 난수 위치 생성, 데이터 이동은 제외했다.
- 모든 크기에서 정렬 결과가 오름차순인지 확인했다.
- 데이터는 실행할 때마다 새로 생성되므로, 아래 값은 **크기마다 1회 실행한 결과**이며 다시 실행하면 값이 달라진다.

## 2. 결과

| 4,000 | 1.235 | 1.245 | 1.187 |
| 8,000 | 1.251 | 1.206 | 1.169 |
| 16,000 | 1.240 | 1.278 | 1.318 |
| 20,000 | 1.241 | 1.193 | 1.192 |

## 3. 데이터 크기 증가에 따른 변화
- 세 방법 모두 n이 커질수록 비교 횟수가 증가했고, n이 2배가 될 때 **약 2.1~2.3배**가 되었다. 예를 들어 First는 11,865 → 27,215(약 2.29배) → 59,105(약 2.17배) → 129,769(약 2.20배) → 277,178(약 2.14배)로 늘었다.
- 비교 횟수가 n의 2배보다 약간 더 크게 늘어나는 것은 n·log₂n 형태의 증가와 일치한다.
- n·log₂n으로 나눈 값은 세 방법 모두 **1.169~1.318** 범위에 있었다. 크기가 커져도 이 값이 크게 커지지 않았으므로, 이 실험에서는 비교 횟수가 n²처럼 급증하지 않았다.

## 4. 피벗 선택 방법별 성능 차이

### 관찰 결과
- **크기별로 비교 횟수가 가장 적은 방법**: Median-3이 3번(4,000 / 8,000 / 20,000), First가 2번(1,000 / 16,000), Random이 1번(2,000)이었다.
- **Median-3 vs First**: 2,000 / 4,000 / 8,000 / 20,000개에서 Median-3이 적었다(3.4~6.5% 감소). 반면 1,000개(0.2% 많음)와 16,000개(6.2% 많음)에서는 First가 더 적었다.
- **Random vs First**: Random이 적은 경우가 3번(2,000 / 8,000 / 20,000), 많은 경우가 3번(1,000 / 4,000 / 16,000)이었다.
- **전체 합계**: Random 849,355 < Median-3 851,267 < First 859,744 순이었으나, 가장 많은 First와 가장 적은 Random의 차이는 약 1.2%에 불과했다.
- 가장 크게 벌어진 것은 8,000개(Median-3이 First보다 6.5% 적음)와 16,000개(Median-3이 First보다 6.2% 많음)였고, 두 결과의 방향이 반대다.

### 해석의 한계
- 이 결과는 크기마다 데이터 1세트, 1회 측정이다. 같은 방법이 크기에 따라 유리하기도 불리하기도 했고(예: Median-3), 16,000개에서는 순위가 다른 크기와 반대로 나타났다.
- 그러므로 이 결과만으로 특정 방법이 항상 낫다고 결론 내리기는 어렵다. 방법 간 차이는 데이터에 따른 변동일 가능성이 있다.

## 5. 피벗 선택이 분할과 비교 횟수에 영향을 주는 이유

- 한 번의 분할에서는 현재 구간의 원소를 피벗과 비교하므로, 분할의 비교 횟수는 **구간 길이에 비례**한다.
- 피벗이 구간의 중간 값에 가까우면 구간이 비슷한 크기의 둘로 나뉜다. 그러면 구간이 빨리 줄어 재귀 깊이가 얕아지고, 각 단계의 비교 횟수 합이 n 안팎이므로 전체 비교가 적어진다.
- 피벗이 구간의 최솟값이나 최댓값에 가까우면 한쪽 구간만 1개 줄어든다. 그러면 깊이가 깊어지고 전체 비교가 크게 늘어난다.
- 따라서 피벗 선택 방법의 성능 차이는 **얼마나 균등하게 분할되는가**로 설명된다.

| 방법 | 분할에 영향을 주는 방식 |
|---|---|
| First | 구간의 맨 앞 값을 쓰므로 그 값이 구간에서 어느 정도 크기인지는 우연에 달려 있다. 이 실험의 데이터는 무작위이므로 First도 극단적으로 치우치지 않았다(n·log₂n 대비 1.19~1.25). |
| Random | 분할마다 위치를 무작위로 고른다. 한 번의 분할 품질은 우연이지만, 분할이 반복되면 좋고 나쁜 분할이 섞인다. 이 실험에서 First와 비슷한 수준(1.19~1.28)이었다. |
| Median-3 | 세 값의 중앙값을 쓰므로 세 값 중 가장 작거나 큰 값이 피벗이 되는 경우는 없다. 그만큼 극단적으로 치우친 분할이 생길 가능성이 줄어든다. 다만 **분할마다 중앙값 결정을 위한 비교(2~3회)가 추가로 든다.** 이 추가 비교는 과제 조건에 따라 비교 횟수에 포함된다. |

- Median-3은 치우친 분할을 줄여 비교를 줄이는 효과가 있고, 동시에 추가 비교라는 비용이 있다. 두 효과가 겹치므로 이득은 크지 않거나 데이터에 따라 사라질 수 있다. 8,000개에서는 이득이 나타났고, 1,000개와 16,000개에서는 나타나지 않았다.

## 6. 어떤 방법이 효과적이었는가
1. 이번 결과에서는 **세 방법에 뚜렷한 우열은 나타나지 않았다.** 6개 크기의 합계 차이는 약 1.2% 이내였고, 크기별 순위도 일정하지 않았다.
2. 그중 **Median-3은 크기별 최솟값이 가장 많았고**(6개 중 3개), 8,000개에서 First보다 6.5% 적게 비교했다. 반면 16,000개에서는 가장 많았다. 합계로는 Random이 가장 적었다.
3. 따라서 이 실험만으로는 한 방법이 효과적이라고 단정하기 어렵다. 치우친 분할을 줄이는 Median-3의 효과가 일부 크기에서 나타났을 가능성은 있으나, 1회 측정이어서 명확하게 확인하기 어렵다.
4. 더 분명한 결론을 얻으려면 크기마다 여러 번 반복해 평균을 비교해야 한다.
